# Privacy policy: moneyincloud autopost

moneyincloud autopost is a personal tool used only by the owner of the @moneyincloud Instagram account and YouTube channel.
It uploads the owner's own videos, titles and captions to the owner's own YouTube channel and Instagram account at scheduled times.

- It does not collect, store or share data about anyone else.
- It uses Google's YouTube Data API only to upload videos to the owner's channel (scope: youtube.upload).
- Access keys are stored as encrypted GitHub Actions secrets and are never published.
- The owner can revoke access at any time at https://myaccount.google.com/permissions.

Contact: via the @moneyincloud Instagram account.
Last updated: 13 November 2026.
